# Downhill Route (내리막 중심 체력 아낌 길찾기) PRD

## 1. Product Summary
Downhill Route is a route-planning service designed to minimize physical exertion in elevated sightseeing areas (starting with Dongincheon). By routing tourists via transport (bus/taxi) to high points first and guiding them downhill, the service reduces fatigue and improves travel experience.

## 2. Core Features
- Elevation-weighted tour sequence optimization
- Automatic transport mode selection per leg
- Persona-based exertion & expense profiles
- Parking lot basecamp loop routing for drivers
- Effort reduction report & elevation profile visualization
- AI Planner explaining route logic in persona voice
